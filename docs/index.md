## نکات مهم

- تمام متون UI به فارسی راست‌چین (RTL) هستند
- تم تیره (dark mode) پیش‌فرض
- JWT token در localStorage ذخیره می‌شود
- تمامی صفحات مدیریت نیاز به لاگین دارند
- API server روی پورت 4000 و Next.js روی پورت 3000 اجرا می‌شود
